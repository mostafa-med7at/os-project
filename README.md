# CPU Scheduling Simulator

## Project Description
The CPU Scheduling Simulator is a Python-based graphical application built using Tkinter. It is designed to visualize and analyze operating system process scheduling algorithms. The application currently supports **Round Robin** and **Priority Scheduling**. 

Users can input a dynamic number of processes along with their respective arrival times, burst times, and priorities. The simulator executes the scheduling algorithms, displaying a Gantt chart visualization of the process execution over time. It also calculates and displays key performance metrics for each process, including Waiting Time, Turnaround Time, and Response Time.

## Requirements
- **Python:** version 3.6 or higher
- **Tkinter:** Standard GUI library for Python (usually included by default with standard Python installations)

## Build / Run Steps
1. Clone or download this project repository to your local machine.
2. Ensure you have Python installed (verify by running `python --version` in your terminal).
3. Open a terminal or command prompt and navigate to the project directory:
   ```bash
   cd "path/to/os project"
   ```
4. Run the main application file:
   ```bash
   python main.py
   ```
   *(Note: On some systems, you may need to use `python3 main.py` or `py main.py`)*
